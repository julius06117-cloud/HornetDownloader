## HornetDownloader v1.5.4 — 修正版（Fix release）

### 修正 / Fixes

- **修复一处崩溃：BT 引擎写一条警告日志就可能让程序直接退出。** 正常双击启动的程序没有控制台（stderr 无效），日志同时写 app.log 和 stderr 时，stderr 写入失败的错误被传给了 BT 引擎的日志适配层，后者遇错直接 panic。v1.5.4 QA 中添加带 `wss://` tracker 的磁力时触发（`crash-*.log` 里是 `panic: write /dev/stderr: The handle is invalid.`）。现在 stderr 只尽力写入、错误忽略，BT 日志处理也不再向上返回错误。
  *Fixed a crash: in a normally launched (GUI, no console) instance, any BitTorrent warning log could kill the app, because the failed stderr write was propagated to anacrolix/log, which panics on handler errors.*
- **下载到网页的失败任务不再每次重启都重新下载。** v1.5.3 会把「直链下载到 HTML 网页」的任务判为失败并删除假文件，但 aria2 的会话里还留着这个任务，每次启动都会把网页再下一遍（再删一遍）。现在判失败后任务会移出 aria2 会话，列表里仍显示为失败（同一个 ID），可以删除，也可以「重新开始」（按原链接重新添加；旧 ID 指向新任务）。v1.5.3 留下的这类任务在下次被重新下载时自动转换。
  *An HTTP task that failed because the URL returned an HTML page is now removed from aria2's session, so it is no longer re-downloaded on every restart. It stays listed as failed (same id) and can still be deleted or retried.*
- **BT 不再往下载文件夹里放 .torrent 副本。** 添加 .torrent 时，种子保存在数据目录 `%APPDATA%\HornetDownloader\bt\meta\<infohash>.torrent`，删除任务时一起删除。旧版本留在下载文件夹里的副本不会被动；重启后任务改用数据目录里的种子；删除任务并勾选「删除文件」时旧副本照旧一并删除。
  *BitTorrent no longer leaves a `.torrent` copy in the download folder; it is stored under the data dir. Existing tasks migrate on restart without touching copies left by older versions.*
- **新增 `hdl version`**（`--json` 输出 JSON；也可 `hdl --version`）：hdl 版本、正在运行的程序版本（不会启动程序）、Go 工具链、构建提交。`/api/v1/ping` 增加 `go` 与 `commit` 字段。
  *New `hdl version [--json]`: hdl version, running app version (never starts the app), Go toolchain, git commit.*

仍使用 Go 1.26.10 构建（见 v1.5.3 说明）。Built with Go 1.26.10.

### 安装 / Install

```powershell
$f = "$env:TEMP\hd-install.ps1"; Invoke-WebRequest https://github.com/julius06117-cloud/HornetDownloader/releases/latest/download/install.ps1 -OutFile $f -UseBasicParsing
powershell -NoProfile -ExecutionPolicy Bypass -File $f -AddToPath -Json
```

Assets: `HornetDownloader-win64.zip`, `HornetDownloader.exe`, `hdl.exe`, `install.ps1`, `SHA256SUMS.txt`, `release.json`. Verify with `SHA256SUMS.txt`.
