## HornetDownloader v1.5.3 — 稳定性修复（Stability release）

### 重点：修复「程序自己消失」/ Fixes the silent exit

- **原因**：v1.5.x 用 Go 1.26.1 构建。Go 1.26.0/1.26.1 在 Windows 上做重叠 UDP 收发时会损坏 goroutine 栈（[golang/go#77975](https://github.com/golang/go/issues/77975)，1.26.2 修复）。BT 下载时 DHT / UDP Tracker 流量一大，程序就以 `0xc0000005` 直接退出，没有任何提示。
- **修复**：改用 **Go 1.26.10** 构建（`go.mod` 固定 `toolchain`）。同样负载下：旧版约 1 分钟崩溃，新版 22 分钟高负载测试无崩溃（见 QA-CHECKLIST.md）。
- **诊断**：崩溃时写 `crash-<时间>.log`，保留上次日志 `app.prev.log`，异常退出后下次启动会提示；`app.log` 每 5 分钟记录内存；可选 `--pprof 127.0.0.1:端口`（仅本机）。

**Root cause:** go1.26.0/1.26.1 corrupt goroutine stacks during overlapped UDP I/O on Windows (golang/go#77975). Under BitTorrent load the app died with an access violation and no message. v1.5.3 is built with go1.26.10; a 22-minute BT + HTTP soak that previously crashed in ~1 minute now runs clean.

### 其它修复 / Other fixes

- 如实的 User-Agent（`HornetDownloader/1.5.3`），不再冒充 Chrome；HTTP 403/418 自动换备用 UA（默认 Wget）重试一次；设置里可配置两者。清华 TUNA、北外 BFSU 等镜像不再 403。
- BT 任务 ID 由 infohash 生成，重启不变；创建时间与来源标记跨重启保留；重启后校验已有数据不再显示假速度；非下载中任务速度为 0。
- 已完成的多文件种子可重新选择文件补下。
- 上传速度正确显示。
- 维基共享资源等媒体页面自动走 yt-dlp；直链下载到 HTML 网页时判为失败并删除假文件（`hdl get` 返回 1）；清理完成任务的 `.aria2` 文件；yt-dlp 任务显示真实文件大小。
- 已删除任务重启后不再复活；暂停/继续后立即退出，重启状态正确。
- 剪贴板同一链接只询问一次，可在设置中关闭。
- 1280×820 @150% 小窗口布局修正；任务详情只有一个「×」；exe 版本信息为 1.5.3；`release.ps1` 兼容 Windows PowerShell 5.1。

### 安装 / Install

```powershell
$f = "$env:TEMP\hd-install.ps1"; Invoke-WebRequest https://github.com/julius06117-cloud/HornetDownloader/releases/latest/download/install.ps1 -OutFile $f -UseBasicParsing
powershell -NoProfile -ExecutionPolicy Bypass -File $f -AddToPath -Json
```

Assets: `HornetDownloader-win64.zip`, `HornetDownloader.exe`, `hdl.exe`, `install.ps1`, `SHA256SUMS.txt`, `release.json`. Verify with `SHA256SUMS.txt`.
